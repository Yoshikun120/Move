# AI สรุปหนัง → คลิปแนวตั้ง 9:16

อัปโหลดวิดีโอ ระบบจะ: ถอดเสียง → AI วางโครงเรื่อง/สคริปต์ → พากย์เสียงไทย → ตัดต่อเป็น 9:16 พร้อมซับและเอฟเฟกต์ → ได้ไฟล์ mp4

## ติดตั้ง

1. ติดตั้ง Python 3.10+ และ **ffmpeg** (ต้องมี `ffmpeg` และ `ffprobe` ใน PATH)
2. ติดตั้งฟอนต์ไทย เช่น Noto Sans Thai (หรือตั้ง `SUB_FONT` เป็นชื่อฟอนต์ที่มีในเครื่อง)
3. ติดตั้งแพ็กเกจ:

```
pip install -r requirements.txt
```

4. ตั้งค่า API key (ใช้ให้ AI เขียนสคริปต์):

```
export ANTHROPIC_API_KEY=sk-ant-xxxx
```

## รัน

```
uvicorn app:app --host 0.0.0.0 --port 8000
```

เปิด http://localhost:8000

## เอฟเฟกต์เสียงและเพลง (ไม่บังคับ)

- ใส่ไฟล์ `whoosh.mp3`, `hit.mp3` ใน `assets/sfx/` ระบบจะใส่ตอนเปลี่ยนฉากให้ตามที่ AI เลือก
- ใส่ `bgm.mp3` ใน `assets/music/` เป็นเพลงประกอบ (เบาๆ ตลอดคลิป)
- ใช้เฉพาะเสียง/เพลงที่ฟรีหรือมีลิขสิทธิ์ใช้ได้

## ข้อควรรู้

- เครื่องที่ไม่มี GPU ถอดเสียงช้า วิดีโอยาว 2 ชม. อาจใช้หลายนาที ปรับรุ่นโมเดลที่ `transcribe(..., model_size="small")` ใน `pipeline.py`
- ใช้ได้ดีกับวิดีโอที่มีบทพูด หนังเงียบ/อนิเมะไม่มีเสียงพูดจะสรุปไม่ได้
- ต้องใช้เฉพาะวิดีโอที่คุณมีสิทธิ์ ถ้านำหนังของคนอื่นไปลง YouTube/TikTok/IG มีโอกาสโดนเคลมลิขสิทธิ์หรือปิดช่อง
- เสียงพากย์ใช้ edge-tts (ต้องต่อเน็ต)
- ถ้าจะเปิดให้คนอื่นใช้ ควรเพิ่มระบบล็อกอิน คิวงาน และลบไฟล์ใน `jobs/` อัตโนมัติ
